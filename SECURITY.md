# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository ("Security" → "Report a vulnerability"). Include the affected package and
version, how to reproduce, and the impact you see.

You'll get an answer within a week. Fixes are released as patch versions of every
`@easy-cms/*` package, with an advisory crediting you unless you prefer otherwise.

## Supported versions

Easy CMS is pre-1.0: only the latest minor release gets security fixes.
